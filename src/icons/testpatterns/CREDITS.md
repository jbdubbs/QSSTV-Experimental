# Test pattern sources

All three are lossless PNGs shown at their original resolution (the Tx code only resamples once, to the mode size).

- `smptebars.png` – "SMPTE Color Bars.svg" by Denelson83, Wikimedia Commons, public domain.
  Rasterised from the SVG at its native 672x504 (no resampling).
- `pm5544.png` – "Philips PM5544.svg" (new version by ebnz), Wikimedia Commons, CC BY 2.5.
  Rasterised from the SVG at its native 768x576 (no resampling).
- `indianhead.png` – the RCA Indian Head test pattern, 640x480, supplied losslessly by a user (issue #72);
  stored as an 8-bit grayscale PNG, pixel-identical to the original BMP.
