QSSTV-Experimental User's Guide

QSSTV-Experimental sends and receives slow-scan television (SSTV) and digital SSTV (HAMDRM) pictures through your sound card. This guide explains how to install it, set it up and use it. It is built on the original QSSTV by Johan Maes, ON4QZ, and maintained by Jason Weisberger, NT0Y; free software under the GNU GPL v3.

Quick start

  1. Install. Linux: download the AppImage, chmod +x it and run it. Windows: run the -win64.exe installer. See Install and first run.
  2. Set up. Open Options > Configuration. On Operator enter your callsign; on Sound choose the audio input and output devices connected to your radio. On CAT set up rig control and PTT if you want the program to key your transmitter. See Configuration.
  3. Receive. Tune your radio (USB) to an SSTV frequency and watch the Receive tab. With Mode on Auto, pictures start and are saved by themselves; they appear in the Gallery. See Receiving.
  4. Transmit. On the Transmit tab load a picture (or use File > TX Test Pattern), choose a mode and press the green button. See Transmitting.
  5. Try it without a radio. Use File > Decode SSTV From File... on a recording, or from a terminal: qsstv-experimental --batch --out-dir pics recording.wav. See Decode from file and command line.

Conventions

Menu items and button names are written like Options > Configuration. Screenshots were made with default settings and placeholder operator data. This guide works offline: every page and picture is in the same folder and no network access is needed to read it. It can be opened from Help > Users Guide.
