Template editor

A template is laid over every picture you transmit: your call sign, the report, the date and time, a logo, a colour bar. You make templates in the template editor, and the Transmit tab and the Gallery use them.

Opening the editor

  • Transmit tab: press Edit... next to the template list to edit the selected template. The arrow next to it starts a new template. (Not available while transmitting.)
  • Gallery > Templates: right-click a template and choose Edit template..., or right-click anywhere in the tab and choose New template....

Only one editor is open at a time; opening another template while it is open puts the template in the same window (you are asked first if there are unsaved changes). Press F1 in the editor to open this page.

The canvas

The canvas is the picture area of one SSTV mode. When a picture is transmitted the whole template is stretched over the whole picture, so make the template at the size of the mode you send most (for example 640 x 496 for PD120, 320 x 256 for Martin 1). A new template starts with the size of the mode currently selected on the Transmit tab; Arrange > Canvas Size... changes it later, and can scale the items along. If you transmit modes of another shape the template is stretched with them.

The grey checkerboard stands for the picture. To see how a template looks on a real picture switch on View > Show Picture Under Template: the picture of the Transmit tab is shown behind the template. It is only a guide and is never saved.

After drawing, the tool goes back to Select. Items are listed in the Layers panel, front item first.

Working with items

Select
Click an item, or draw a rectangle around several. Shift- or Ctrl-click adds or removes an item; Ctrl+A selects everything. Items can also be picked in the Layers panel, which is the only way to select a locked item.
Move
Drag an item, or use the arrow keys (1 pixel; with Shift 10 pixels). Dragging snaps to the edges and middle of the canvas and of other items (pink guide lines); hold Alt to switch snapping off for a moment, Shift to move in a straight line.
Resize
Drag a square handle. For a picture a corner keeps its proportions (hold Shift to change them), for other items hold Shift to keep them. A corner of a text makes its letters bigger or smaller.
Rotate
Drag the round handle above the item (hold Shift for steps of 15 degrees), or type the angle in the Properties panel, where you also find skew and opacity.
Edit a text
Double-click it, or select it and press Enter or F2. Ctrl+Enter or a click outside is done, Esc cancels. The Properties panel has a text box too.
Duplicate, copy, paste
Ctrl+D, Ctrl+C, Ctrl+X and Ctrl+V. Items copy between two editor windows or programs; a picture or text copied elsewhere pastes as a new item.
Arrange
The Arrange menu and toolbar: bring in front or send to back, align items to each other (a single item aligns to the canvas), spread three or more evenly, and lock items so they cannot be moved by accident.
Zoom and pan
Ctrl + mouse wheel zooms, Ctrl+0 fits the canvas in the window, Ctrl+1 shows it at 100 %. Drag with the middle mouse button, or hold Space and drag, to pan.
Undo
Everything can be undone: Ctrl+Z, redo with Ctrl+Shift+Z or Ctrl+Y. A whole drag is one step, and so is a run of typing in one field. Edit > Delete All Items asks first and can be undone too.

Colours, gradients, outlines and fonts

The Properties panel changes every selected item at once. Its sections run from what the item is to where it sits: the text or picture first, then fill, outline, opacity and lock, and last position, size and rotation, which you mostly set by dragging on the canvas.

Fill
A solid colour (with transparency) or a linear, radial or conical gradient for text, rectangles and ellipses.
Outline
Colour, width and style of the edge. For a line this is the line; for pictures and the replay window it is the border. White text with a black outline stays readable on any picture.
Font
Family, size in points, weight, italic, underline and letter spacing. A template remembers the font by name. If a computer does not have the font the text is drawn in another font; the Properties panel then shows a notice, and the template keeps the name.

Macros

A text may contain macros that are replaced when the picture is transmitted. The Macros tab next to the Layers panel lists them; double-click one to put it into the selected text (or into a new text). View > Preview Macros shows sample values on the canvas; the template itself keeps the macros.

MacroReplaced by
%cCall sign of the station you send to (the To box on the Transmit tab)
%rThe RSV report
%oThe operator name (the Op box)
%mYour call sign (Configuration > Operator)
%f, %nYour first and last name
%q, %lYour location name and grid locator
%t, %dThe UTC time (hh:mm) and date (yyyy/MM/dd)
%vThe QSSTV version
%x, %y, %zThe three large text boxes on the Transmit tab
%sThe signal quality (MER, dB) of the last received DRM picture
%%A percent sign

A macro that does not exist prints nothing; the Properties panel warns about it.

Saving and opening

Templates are saved in your templates folder (Configuration > Directories) as .qtempl files. This is a new, readable text format; it is not understood by the old QSSTV 9. File > Save and Save As write it, Revert loads the saved file again, and Open Recent lists the last templates. The title bar shows a * while there are unsaved changes, and closing the editor asks what to do with them.

Templates from earlier versions (.templ) open as well. The editor tells you the template was imported; saving writes a new .qtempl file and never touches the old one. Once a .qtempl exists the template list shows it instead of the old file with the same name; the old file stays on disk. Damaged or truncated files are refused with a message and cannot crash the program. A template that cannot be read when a picture is transmitted is skipped and the picture goes out without it (the reason is in the log).

Editing a picture

The template editor is only for templates. To change a picture itself (crop it, adjust it, paint on it), right-click it on the Transmit tab or in the Gallery's TX Stock tab and choose Edit picture..., or press the pencil on the Transmit tab. QSSTV makes a copy named like holiday-edit.png, opens it in your picture editor and, as soon as you save it there, uses it as the transmit picture. The original is never changed. Copies are kept in the TX Stock gallery (next to the original when it is there already); a copy you never saved in your editor is removed again when QSSTV closes (or after eight hours).

The picture editor is chosen under Configuration > Gui > Picture editor: type a command, using %f for the file, or press Detect to pick one of the editors found (GIMP, Krita, KolourPaint, Pinta and others). Left empty, the first one found is used, and failing that the system's default program for pictures.
