Credits and licenses

Authors

  • Johan Maes, ON4QZ wrote QSSTV (copyright 2000-2019, https://www.qsl.net/o/on4qz). QSSTV-Experimental is built on QSSTV 9.5.11.
  • Jason Weisberger, NT0Y maintains QSSTV-Experimental (https://github.com/jbdubbs/QSSTV-Experimental).
  • PA0MBO: the HAMDRM software in QSSTV is based on RX/TXAMADRM.
  • Contributions to the Qt 6, macOS and FreeBSD porting and to fixes came from Jörg Wunsch (DL8DTL), Daniele Forsi, hspil, Ruxton, AsciiWolf, Barry de Graaff, Greg Tangey and Sam Saccone.

The program's About box keeps the original copyright and attribution.

Third-party code and libraries

The program contains code from QSSTV (Johan Maes, ON4QZ), RXAMADRM (PA0MBO), the Dream DRM software, Phil Karn's Reed-Solomon codec and others, and the binary releases bundle Qt, Hamlib, FFTW and image libraries. The About box also mentions MixViews, Maia XML-RPC and the Papirus icons. The optional city and state lookup uses the Nominatim service of OpenStreetMap (place names are data © OpenStreetMap contributors, available under the Open Database License). The complete list with each license is in THIRD_PARTY_LICENSES.md in the source tree, installed with every release, and shown from Help > About > Third-party licenses....
