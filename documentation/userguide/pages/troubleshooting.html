The program will not start

The AppImage does nothing or complains about FUSE
Run it with APPIMAGE_EXTRACT_AND_RUN=1 ./QSSTV-Experimental-*.AppImage, or install FUSE 2 for your distribution.
"Permission denied"
Make it executable: chmod +x QSSTV-Experimental-*.AppImage.
Building from source fails
Check BUILDING.md for the exact packages. When reporting a problem include your operating system and version, the Qt version and the real compiler or linker error.

Audio

No signal, flat spectrum
Open Configuration > Sound and check that the right Input Audio Device is chosen and that the radio's audio is connected to that device. Check the operating system's own volume and mute settings and microphone privacy settings.
Wrong or missing devices
The device lists show the devices the operating system offers when the dialog opens. After plugging in a USB sound interface, reopen the dialog. If the device vanishes and comes back (USB unplug, Windows sleep and resume), the program re-arms the audio on its own.
An error box titled "Soundcard error"
The device could not be opened. Choose another device or close the other program that is using it.
Output level too low with an interface that sums the two channels
Tick Send audio to both channels on the Sound page (it is on by default); lower the drive level on the radio or interface if that is too much.

Receiving

The receiver never starts on a picture
Increase Sensitivity; make sure Mode is Auto; check the radio is in USB mode and tuned so the signal sits between the red markers in the spectrum; check the audio level.
Pictures are slanted
Turn on Auto Slant. If it happens with every station, calibrate your sound card.
Pictures are noisy or have colored streaks
This is weak signal or interference; the picture mirrors the band conditions. A more sensitive setting does not help once the signal is that weak.
A picture that faded is split into two pictures
The receiver gives up on a picture when its signal has been gone longer than the Sensitivity setting waits (10, 20 or 30 s, see SSTV settings); the signal coming back then starts a new picture. Increase Sensitivity to wait longer. A fade in the first dozen lines of a picture that began without its VIS code is not waited for.
Pictures that are nothing but noise
The receiver started on noise that looked like sync pulses. Lower Sensitivity, or raise Save if Complete (%) so that interrupted pictures are kept less easily. Noise is given up after a few lines and does not stop the receiver from starting on a real picture.
An interrupted picture was not saved
It was below the Save if Complete (%) threshold. Lower it if you want to keep partial pictures.
I cannot switch to the other tab (DRM/SSTV)
The other mode's tabs are locked while a reception or transmission is in progress. Stop it first.
"Who is on?" is empty, or I do not appear in other people's list
Check that a Host is entered on Configuration > Hybrid and that Test connection succeeds; that both stations use the same server and Online Status Directory; and that the Operator page's online status option is ticked. The status is published once when the program starts in DRM mode and is listed for only one hour, so restart the program in DRM mode to publish again. See Operator.
The "Fix File" button does nothing
It needs an incomplete DRM picture and DRM mode with the program idle; otherwise you are told that there is nothing to request.
DRM never gets past TIME or FRAME
The signal is too weak or off-frequency. Check that the other station's mode, bandwidth and robustness are within what you can receive, and watch the MER values.

Transmitting and PTT

The radio does not go to transmit
Check Configuration > CAT: the PTT method must match your hardware. The status bar's PTT indicator turns red when the program is keying. Use Restart CAT Interface after changing settings. If the radio switches too late, increase TX on Delay, or tick VOX on the Transmit tab to send a leading tone.
"No image loaded"
Load a picture first (or use File > TX Test Pattern).
"Transmission busy, editor not available"
You cannot edit a picture or open the template editor while transmitting. Stop the transmission first.
Edit picture does nothing, or opens the wrong program
Set the picture editor under Configuration > Gui. Sandboxed installs (Flatpak, Snap) cannot start other programs by themselves; the system's default picture program is used then.
My template shows the wrong font
The font is not installed on this computer; another one is used. The template editor shows a notice for such a text and keeps the font name, so the template still looks right on a computer that has the font.
Distorted transmit audio
Lower the output level and check the radio's ALC. Use the tone test (see Tones and sweeps).
The picture is cropped or letterboxed on the transmit side
Change Framing between Stretch, Crop, Fit and Free.
The GPS button says it cannot open the port
Check the port in Configuration > GPS (Rescan lists the ports found; on Linux the /dev/serial/by-id names). On Linux your user must be allowed to use the serial port, usually by being in the dialout group; log out and in again after joining it. Close any other program that is reading the receiver, and use a port other than the CAT and PTT ports.
"No GPS data" or "has no position fix yet"
"No GPS data" means nothing readable arrived: the port or the baud rate is wrong (most receivers use 4800 or 9600, try the other one). "No position fix yet" means the receiver talks but has not found its position; give it a clear view of the sky, a cold start can take several minutes. Test on the GPS page tells which of the two you have.
The Place box stays empty
Tick Look up the city and state on the internet on the GPS page and make sure the computer is online; Test there shows the reason when the lookup fails. On Linux the OpenSSL libraries must be installed for the secure connection. The box can always be filled in by hand.

Files and settings

Where are my pictures?
In the folders on Configuration > Directories; by default subfolders of the program's data folder.
My settings were not saved
Settings are written when you quit normally with File > Exit. A crash or a kill loses the changes since the program started.
Which image formats can I load?
PNG, JPEG, GIF, BMP and JPEG 2000, and WebP, AVIF and HEIC (the latter two need the format plugins; the AppImage and Windows packages include them).
The program does not log to my logger
Contacts are broadcast as ADIF records over UDP to localhost, port 2333 by default. Point your logger's ADIF UDP listener at that port.

FAQ

Can I use it without a radio connected?
Yes. Leave CAT disabled; you can still decode recordings, encode WAV files, browse the gallery and edit pictures.
Is it compatible with other SSTV programs?
It is compatible with most of MMSSTV and EasyPal modes. The new JB60 mode is only available in QSSTV-Experimental.
Can I decode a recording of an SSTV transmission?
Yes: File > Decode SSTV From File..., or --batch from the command line. For a receiver without a window, --listen takes the pictures from the sound card.
Where do I report a bug or ask for a feature?
On the GitHub issue tracker. Include your operating system, the program version (Help > About), and what you were doing.
