KG-STV (experimental)

Choose the KG-STV (experimental) tab on Receive and Transmit. This is a separate digital mode alongside SSTV and HAMDRM, using 320×240 images, standalone ASCII text and manual block repair.

Receive and send

Select MSK or 4L-FSK to match the peer; the RX/TX choices are synchronized. The receiver shows how many of the 300 image blocks have arrived. Incoming text appears as plain text with UTC time.

Use the normal Start button for the current image and template. The normal template editor is retained; KG-STV uses a single 320×240 frame. Compression 0..15 (higher means smaller blocks) and payload error correction are set on the TX tab. Stitched grids, repeater and camera-beacon transmission are disabled for this experimental mode.

For text, enter 1..200 ASCII bytes and press Send Text. No image is needed. A local send completion does not acknowledge reception by the peer. Unsupported characters are rejected rather than silently changed.

Missing blocks and BSR

After an incomplete image pass finishes, use Request missing blocks (BSR). The sender manually replies with Send requested blocks from cached image. That cache is the last completed image transmission, even if a different picture has since been loaded. There are no automatic replies.

Stop cancels transmission. The application's busy-mode lock applies. You may save partial images manually; complete images can be saved automatically in the digital RX directory with the KGSTV_ prefix.

Audio files and headless use

The audio-file picker works on the KG-STV tab. The command line can receive recordings, listen live, or encode an image into a WAV file:

qsstv-experimental --batch --kgstv --kgstv-four-level --out-dir received recording.mp3
qsstv-experimental --listen --kgstv --kgstv-four-level --out-dir received
qsstv-experimental --encode image.png --kgstv --kgstv-four-level --wav-out image.wav

Omit --kgstv-four-level for MSK. KG-STV cannot be combined with --drm. Headless KG-STV file reception and encoding do not open audio cards or operate CAT/PTT, and do not write settings. Live listening uses the normal selected input. Batch reception saves complete PNG images and received text files in the output directory.

Validation limits

External reference recordings decode successfully: a complete 300-block image and an unchanged ASCII text message. Synthetic loss/repair tests and file TX/RX loopbacks also pass. These results do not prove original-application reception of our transmissions or original BSR interoperability. Non-ASCII encoding, exact rendering, noisy channels and real audio/CAT/PTT operation still need independent validation. Treat KG-STV as experimental.
